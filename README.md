# Portfolio — Rafael Vales

Next.js, TypeScript, App Router y Tailwind CSS. Desarrollo local: `npm run dev`; producción: `npm run build`; calidad: `npm run lint`.

La compilación usa Webpack: verificada correctamente en este entorno, donde Turbopack encontró una restricción al crear un proceso para CSS.

## Alcance actual
Primera implementación del viewport inicial aprobado: navbar, presentación y entrada a los proyectos. Fondo claro y sistema tipográfico nativo. Capturas reales de TripPilot en public/images/trippilot. Los otros proyectos tienen contenido provisional explícito. Sobre mí y contacto son anclas de continuidad, pendientes de diseño detallado; todavía no hay email o redes confirmados ni páginas de casos.
